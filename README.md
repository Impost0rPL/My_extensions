# 📍 LocateNow

Rozszerzenie do Edge/Chrome — odczytuje lokalizację z **OpenGuessr** i pokazuje kraj, miasto i dzielnicę oraz mini-mapkę **Google Maps**.

## Instalacja

**Edge / Chrome:**
1. Pobierz repo (Release → LocateNow.zip) i rozpakuj.
2. `edge://extensions/` → **Tryb dewelopera** → **Załaduj rozpakowane** → wskaż folder.

**Lemur Browser (Android):**
Spakuj folder do ZIP (pliki na wierzchu) → Ustawienia → **Zainstaluj rozszerzenie lokalne**.

## Użycie
- **📍 / 👁️** – pokaż/ukryj panel
- **🗺️ Pokaż na mapie** – mini-mapka Google Maps
- **📋 Kopiuj** – skopiuj współrzędne
